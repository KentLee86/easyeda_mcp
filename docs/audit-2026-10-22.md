## 수정 방침

1. `npm audit fix`: 기존 semver 범위에서 lock 갱신.
2. 직접 SDK 최소 버전을 `^1.32.1`, Vitest를 `^3.2.7`로 올려 취약 버전 재해석을 방지.
3. 직접 esbuild를 `^0.24.2`에서 `^0.28.2`로 minor 범프. 0.x minor는 호환을 가정할 수 없으므로 실제 번들·패키징·live 주입으로 확인한다. Vite 내부의 esbuild를 이 버전으로 강제하지 않는다.
4. Vite·Vitest의 major 범프나 package manager override로 상위 패키지의 지원 범위를 우회하지 않는다.
